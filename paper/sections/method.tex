\section{Experimental Method}
\label{sec:method}

\paragraph{FEMNIST.}
LEAF-preprocessed FEMNIST~\cite{caldas2018leaf}: 198 writers as clients, 36{,}700 training and 4{,}174 test samples, using LEAF's per-sample split, so writers appear in both sets. The model is a CNN of 161{,}438 parameters. Training uses SGD at learning rate 0.1, 3 local epochs, batch size 32, 20 clients per round and 100 rounds. The rate was selected by training loss; 0.2 was rejected after honest FedAvg diverged or spiked. Attacked runs mark 40 of 198 clients malicious with exactly 4 per round; $f=b=4$. Three seeds per condition.

\paragraph{Speech Commands.}
Speech Commands v0.02~\cite{warden2018speech} with its official speaker-disjoint split, 35 classes, and 64-band log-mel features of shape $(1,64,101)$. Clients are 200 speakers from the training split, averaging about 38 clips, 7{,}698 clips in all, so most of the split is unused. The model is BC-ResNet-8~\cite{kim2021bcresnet} adapted to 64 mel bands (335{,}811 parameters). Training uses batch size 8, 2 local epochs, 11 clients per round and 40 rounds, with 36 of 200 clients malicious, exactly 2 per round, and $f=b=2$. These settings were forced by CPU cost, about 33 minutes per run. The learning rate of 0.2 was chosen on validation accuracy among $\{0.1,0.2\}$; it is the largest value tried. \textbf{Forty rounds is not convergence}, so the Speech results describe early federated training. Scores are computed after training on all 11{,}005 test clips. In-loop evaluation used a fixed subset of 300 clips, and the post-hoc tool refuses any checkpoint that does not reproduce the recorded subset accuracy exactly.

\paragraph{Transformer models.}
LoRA-AST is an AST-\emph{style} spectrogram transformer~\cite{gong2021ast} with LoRA adapters~\cite{hu2022lora} on a \textbf{randomly initialised, frozen backbone}; it is not pretrained and is not a reproduction of AST. ViT-Tiny~\cite{dosovitskiy2021vit} and LoRA-ViT were exercised only in smoke and pilot runs because of their CPU cost.

\paragraph{Metrics and statistics.}
Clean test accuracy is summarised per seed as the mean of the last 10 rounds on FEMNIST and as the final full-test score on Speech Commands. Tables give the mean and sample standard deviation across seeds. Comparisons pair runs by seed and report a two-sided 95\% $t$ interval. With three seeds these intervals are wide and we report no $p$-values. Backdoor ASR is measured on held-out samples whose label is not the target, with the full trigger, and is never mixed into clean accuracy. Filtering is summarised as the fraction of malicious clients rejected (TPR) and the fraction of honest clients rejected (FPR).

\paragraph{Integrity.}
Analysis excludes any run that is not marked completed, lacks a contiguous metric record, contains a non-finite metric, or lacks a finite final-round checkpoint matching its configuration hash. No completed run was discarded for its outcome. Tables are generated by script from the run directories.

\paragraph{Execution platforms and confounds.}
Runs executed on a Core Ultra 5 226V laptop, CPU only, with one torch thread per job. The first 45 FEMNIST runs ran under WSL2 with Python 3.10, and all others ran on native Windows with Python 3.11, on identical package versions. Results are not bitwise identical across platforms, so we compare only end-of-training summaries between them, and honest runs use uniform sampling while attacked runs use stratified sampling. Section~\ref{sec:ablations} tests both with Windows replays and a no-op control. Fourteen control and replay runs were invalidated by an operator error, when two queues wrote to the same directories. An automated check of round counts caught this. They are excluded, kept on disk, and were rerun into new directories; the main grids were audited and were not affected.
